# TurulLauncher 4.2.1

## Player-facing fixes
- A Modok oldal most mindig az aktív Instance Minecraft-verzióját és loaderét használja.
- A Modrinth keresés és telepítés backend oldalon sem fogad el elavult UI loader/verzió értéket.
- Fabric Instance esetén a modkereső nem eshet vissza tévesen `none` loaderre.
- Gyári visszaállítás előtt kötelező beírni: `I CONFIRM` vagy `CONFIRM`.
- A gyári visszaállítás megerősítését a backend is ellenőrzi.
