# TurulLauncher 4.3.8

- Remembers installed Modrinth mods per active Instance.
- Mods that came from a Modrinth modpack are marked as installed in search results.
- Mod detail view also shows installed state and disables duplicate install.
- Existing/older modpack JARs are identified once by SHA-512 through Modrinth and cached locally.
- New .mrpack installs cache project/version IDs from standard Modrinth CDN URLs immediately.
