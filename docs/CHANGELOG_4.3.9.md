# TurulLauncher 4.4.0

## Added
- Copy selected content from one Instance to another.
- First-run Hungarian / English language selection.
- Persistent language controls in Settings.

## Instance copy categories
- Mods, shaders, worlds, resource packs, screenshots and configs.
- Minecraft settings and server list.
- Optional map/waypoint, schematic and replay folders.
- Preview of total size, file count and conflicts.
- Skip/overwrite/ask conflict handling.
