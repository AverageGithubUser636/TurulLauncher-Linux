# TurulLauncher 4.4.0

## Added
- Game launch settings for Minecraft version, Modrinth modpack version and per-Instance RAM.
- Bidirectional Minecraft/modpack version synchronization.
- Compatibility check for Fabric loader, installed Modrinth mods, resource packs and modpack versions.
- Local embedded icon extraction for manually copied Fabric JAR mods.
- Minecraft world `icon.png` previews in Library.

## Changed
- Copy-to-Instance dialog is viewport-safe and scrollable with an always reachable close button.
- Modpack version chooser stays inside its result card and scrolls internally.
- Duplicate modpack installs use `Name-2`, `Name-3`, etc.
- Installed mod removal is presented as an explicit delete action.
