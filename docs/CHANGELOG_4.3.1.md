# TurulLauncher 4.3.3

- Új, kompakt és mozgatható TurulLauncher Updater ablak.
- Valódi letöltési progress, sebesség és hátralévő idő.
- Pause/Resume, Cancel és kinyitható Log panel.
- Az updater most maga tölti le a frissítést, így a progress nem csak animáció.
- Update letöltés folytatható részleges `.part` fájlból, ha a szerver támogatja a Range kérést.
- Launcher ablak automatikusan a monitor munkaterületéhez igazodik.
- 1366×768 és alacsony magasságú ablakokra külön responsive/DPI UI szabályok.
- `TurulMC.Updater.exe --preview` és `preview-updater.cmd` vizuális teszteléshez.
- Build hotfix: javítva a Launcher updater-indítási C# fordítási hibája (`CS0201`).
