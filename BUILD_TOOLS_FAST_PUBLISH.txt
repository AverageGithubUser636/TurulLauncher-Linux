TurulLauncher fast publish tooling

- publish.cmd / build-installer.cmd automatically detect aria2c and 7-Zip.
- If aria2c is missing, a portable aria2c is downloaded to tools\bin\aria2c.exe.
- If 7-Zip is missing, portable 7-Zip console files are downloaded to tools\bin\7zip\.
- No system-wide installation or admin rights are required for these portable tools.
- ZIP creation uses 7-Zip multithreading (-mmt=on) and compression level 3 by default.
- Override ZIP compression level with e.g.:
    set TURUL_ZIP_LEVEL=1
  before running publish-all.cmd for maximum speed.
- VC++ Redistributable download uses aria2c when available and falls back to Invoke-WebRequest.
- If the helper tools cannot be downloaded, the old PowerShell ZIP/download fallback remains available.
