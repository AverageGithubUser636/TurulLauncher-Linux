TurulLauncher Version: 4.5.0

[+]
Automatikus Java telepítés: ami hiányzik, azt a launcher letölti (Eclipse Temurin JRE)
Java verziótérkép a Minecraft-verzióhoz (8 / 16 / 17 / 21 / 25), a verzió-JSON az úr
Java kezelő a Beállításokban: felismert és telepített runtime-ok, egy kattintásos telepítés, törlés
Doctor panel a Játék oldalon: 17 ellenőrzés egy helyen, ahol lehet, egy kattintásos javítással
Doctor ellenőrzi: Java (próba időkorláttal), Instance mappa, írási jog, szabad hely, VC++/WebView2,
Mojang + Modrinth + frissítés-szerver elérés, logok állapota, settings/instances JSON épsége
Support Bundle most a Doctor jelentést is tartalmazza, és a GUI/CLI ugyanazt a csomagot készíti
CLI: doctor, support, java list / java install [major] / java remove <id>

[*]
A Java felismerés aszinkron és gyorsítótárazott: egy nem válaszoló java.exe nem fagyasztja le a launchert
A Java telepítés SHA-256-tal ellenőrzött, csak github.com / *.githubusercontent.com / api.adoptium.net forrásból
A kicsomagolás zip-slip védett, a csomagméret és fájlszám korlátos
Egyetlen kompatibilitási szabály (JavaVersionMap) a Doctor, az indítás és a CLI számára
Teszt csomagverziók rögzítve a megismételhető restore-hoz

[-]
Néma várakozás, ha a Minecraft-verzióhoz nem volt megfelelő Java (helyette letöltés vagy érthető hiba)
Blokkoló `java -version` próba, ami egy nem válaszoló Java-nál beragadhatott
Külön, ad-hoc support ZIP a GUI-ban (helyette közös Core szolgáltatás)
